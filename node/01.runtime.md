## Runtime 就是程序的运行环境

Java: Java 虚拟机
JavaScript: 浏览器环境/node环境

go 的 Runtime 特点

1. 没有虚拟机的机制。
2. Runtime 作为程序的一部分打包二进制产物。
3. Runtime 随用户程序一起运行。
4. Runtime 与用户程序没有明显界限，直接调用函数调用。

go 的 Runtime 能力

1. 内存管理能力
2. 垃圾回收能力(GC)
3. 超强的并发能力
4. 能做好跨系统兼容
5. 一些 go 的关键其实就是 Runtime 下的函数
6. Go 的 Runtime 是和程序一起绑定并运行的。
