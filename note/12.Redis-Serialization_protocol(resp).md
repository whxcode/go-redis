# Redis 协议 (RESP 协议)

## 正常回复

- 以 + 开头，以 \r\n 结尾的字符串形式
  eg: "+OK\r\n"

## 错误回复

- 以 - 开头,以 \r\n 结尾的字符串形式
  eg: "-Error message\r\n"

## 整数

- 以:开头,以\r\n结尾的字符串形式
  eg: ":123456\r\n"

## 多行字符串

- 以 $ 开头，后跟实际发送的字节数，以\r\n结尾
  也是一种拆包协议
  eg: "$9\r\nimooc.com\\r\n"
  eg: "$0\r\n\r\n" 空字符串
  eg: "$14\r\nimooc\r\nmoody\r\n" 有字节数的好处；内部也可以正确处理 \r\n

  特殊情况 空回复 (nil)
  eg: "$-1\r\n"

## 数组

- 以 * 开头，后跟成员个数
  eg: "*3\r\n$3\r\nSET\r\n$3\r\nkey\r\n$5\r\nvalue\r\n"
